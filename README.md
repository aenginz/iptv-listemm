# Yapılacaklar (örnek Android uygulaması)

Basit bir yapılacaklar listesi. Kotlin ile yazıldı.

- Görev ekle: üstteki kutuya yaz, **Ekle**'ye bas
- Tamamlandı: göreve **dokun**
- Sil: göreve **basılı tut**
- Liste telefonda saklanır, uygulama kapanınca kaybolmaz

## APK nasıl alınır?

Her push'ta GitHub Actions APK'yı otomatik derler:
**Actions** sekmesi → son "APK Derle" çalışması → en alttaki **Yapilacaklar-apk** dosyasını indir
→ zip'i aç → `app-debug.apk`'yı telefona kur ("bilinmeyen kaynaklardan yükleme"ye izin vermen gerekir).
